# Temporary braces depth backport

`braces-3.0.3-depth.json` applies only five security hunks from [upstream PR 72](https://github.com/micromatch/braces/pull/72), pinned at `28d440b5dd449dbf1fe6f3506cf94ecca4d02660`, to the published `braces@3.0.3` sources. Full original and patched SHA-256 values are required. This preserves the published parser's unrelated behavior and the original stringify parent handling. The package retains its original name and version.

The patch limits brace/parenthesis nesting and caller-supplied AST walker depth to 100, honors stricter fractional limits, and rejects cyclic expansion parent chains. It does not claim to bound all expansion cardinality or replace future upstream security releases.

As in the pinned upstream fix, unmatched/mismatched delimiters can accumulate nesting and reach the limit. Inputs containing more than 100 unresolved opens can now be rejected even if the old parser tolerated them. Ordinary content globs are unchanged.

Source changes retain the upstream MIT license: copyright 2014–present Jon Schlinkert. See [LICENSE](braces-LICENSE). Remove this temporary backport when an official security release can replace it after compatibility verification. A successful install is insufficient evidence by itself: governance must independently verify the actual patched bytes and development-only advisory graph.

`npm ci --legacy-peer-deps` applies the backport through `postinstall`. Installing with `--ignore-scripts` leaves it unapplied; governance then refuses remediation. Production-only installs without this development package need no patch. The audit gate preserves the raw npm findings and recognizes only this advisory on verified installed bytes, actual consumer resolution, one locked package instance, and the development-only Tailwind graph. Unrelated advisories and production exposure still fail. The zero audit baseline and exception list remain unchanged, including when regenerating the baseline.

Validation on October 3, 2026: 25 regression/refusal controls pass, including a published-source stack-exhaustion negative control under a fixed V8 stack budget, direct AST/cyclic parent rejection, unchanged shallow pattern output, off-lock nested dependencies and malformed audit reports. The published 3.0.3 suite passes all 764 tests before and after patching. A fresh isolated Node 24 install and audit pass with all seven propagated package findings visible and zero unresolved findings; its generated baseline remains zero. The application build has seven CSS artifacts byte-identical to the pre-backport build. Full Vitest passes 3,612 tests with 95 opt-in runtime cases skipped; lint, typecheck, governance and build pass. These results do not certify actual external delivery or run the opt-in staffing runtime suites.
